E*TRADE 거래내역 CSV 가져오기

E*TRADE에서 다운로드한 거래내역(Transactions / Orders) CSV 파일을 불러와 매매 일지로 자동 변환합니다.

E*TRADE에서 CSV 다운로드 방법:

1. E*TRADE 웹사이트 로그인 → 상단 메뉴 Accounts > Transactions (또는 Orders) 클릭

2. 원하는 조회 기간(예: 지난 30일 / 특정 월)을 선택

3. 우측 상단의 Download 또는 Export 버튼 클릭 → CSV 파일 저장

E*TRADE CSV 파일 선택 또는 여기로 드래그 모든 데이터 처리는 사용자 브라우저 내부에서만 안전하게 실행됩니다.
